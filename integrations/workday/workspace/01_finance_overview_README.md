# Synthetic Finance Overview

> **SYNTHETIC TUTORIAL DATA — INVENTED WORKTAGS AND AMOUNTS. THE COLUMNS ARE SIMPLIFIED AND DO NOT REPRODUCE A REAL BYU REPORT LAYOUT.**

This file stands in for a budget-versus-actuals overview that a faculty member might run in Workday for the worktags they are responsible for.

- **Report:** Budget vs Actuals Overview by Driver Worktag (synthetic stand-in)
- **Period:** September 2026, run October 15, 2026
- **Active filters shown on the report:** Exclude closed worktags = Yes; Exclude worktags with no activity this fiscal year = Yes
- **Column definitions:** `remaining_balance` = `budget` − `actuals` − `encumbrances`. `period_end` is the award end date for grants and blank for other types.
- **Auxiliary note shown on the report:** For auxiliary worktags, budget and remaining columns show expense-budget variance, not cash available.
