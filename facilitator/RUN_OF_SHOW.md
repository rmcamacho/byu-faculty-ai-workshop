# Twenty-Minute Run of Show

Before the session, open the LS development template and run `python3 scripts/build_workshop.py` to check every answer. Keep worked answers open as a fallback. Rehearse the browser connection on a participant machine before promising a particular product setup.

- 0:00–2:00: Show Development and Start Here. Explain that LS materials are real copies and the students/results are entirely fictional attachments.
- 2:00–10:00: Run Learning Suite Exercise 1. Reveal four outreach candidates, D+ separately and the three exclusion cases. Open Homework 3.3 in LS to connect the analysis to actual teaching material. Review one draft aloud.
- 10:00–15:00: Run Exercise 2. Compare denominators, open Lecture 10 slides 11 and 22, and show the sign check and worked supernode example. Ask the audience for the two equations before showing the solution.
- 15:00–18:00: Run Exercise 3. Show a no-change-needed policy result if appropriate and the exact deadline preview. A live edit needs explicit approval of the target/change and a saved-state check. Use the preview alone if time is short.
- 18:00–20:00: Show the fictional TA follow-up and point to the README path, including the optional Kuali and Workday tutorials.

Fallback: use the package's worked answers and local CSVs if browser/authentication is unavailable. Say explicitly that this part is the prepared fallback. Do not substitute a live student gradebook on the projector. For the final rehearsal, verify a second instructor can copy the course and download its attachment; owner sharing settings alone do not prove that end-to-end result.
